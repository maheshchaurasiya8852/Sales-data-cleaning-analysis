# Sales Data Cleaning and Analysis

## Project Overview

This project focuses on cleaning and analyzing a messy sales dataset using Python and Pandas.

The dataset contains information about sales transactions, including date, product, region, sales amount, and quantity sold.

## Tools and Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- GitHub

## Data Cleaning

The following tasks were performed:

- Removed duplicate rows
- Handled missing values
- Standardized region names
- Converted Date column to datetime
- Checked data types
- Verified missing values

## Analysis Performed

- Total Sales
- Average Sales
- Product-wise Sales
- Region-wise Sales
- Product-wise Quantity
- Region and Product-wise Sales

## Key Insights

- Total Sales: ₹267,000
- Average Sales: ₹22,250
- Laptop generated the highest sales: ₹215,000
- North region recorded the highest sales: ₹215,000
- Mouse had the highest quantity sold: 15 units
